# Human labelling sheet - instructions (40 items, ~25 minutes)

File: `runs/rageval/human_labeling.csv` (generated by `python -m arretrieval.rageval.export_human`) (open in Excel/Numbers/Google Sheets; keep UTF-8, Arabic must display right-to-left correctly).
**Do not open `human_labeling_key.json` before you finish** - it contains the planted-error truth and the judges' verdicts.
Half the rows are real answers from the RAG system, half are answers with a deliberately planted defect; the sheet does not say which.

For every row read: the question, the reference answer, the (up to three) retrieved documents, and the system's answer, then fill
three columns with **1 (yes/good)** or **0 (no/bad)**:

| column | put 1 if ... | put 0 if ... |
|---|---|---|
| `human_faithful` | every claim in the answer is stated in (or directly follows from) the documents shown | any number, name or fact is missing from / contradicts the documents; a refusal that is *false* (the documents do contain the answer) is not faithful either - leave blank if you are unsure how to rate refusals |
| `human_correct` | the answer gives the reference answer's fact(s), nothing contradicting them (wording, language, extra harmless detail, digit script ٣ vs 3 do not matter) | wrong/different number or entity, a part of the reference missing, a refusal when the reference has a fact, a specific answer when the reference says no answer exists |
| `human_acceptable` | you would be happy to show this answer to a customer: faithful AND correct AND written in the question's language AND the cited `[P...]` document really contains the claim AND it refuses exactly when no document contains the answer | any of those fails |

`human_notes` is free text (write *why* when you disagree with your first instinct - those notes are the most valuable part).
Leave a cell blank rather than guessing; partial files work.

When done:

```bash
python -m arretrieval.rageval.agreement            # kappa + confusion matrices, human vs every judge, and human vs planted truth
```

What to look at first in the output: (1) *human vs planted truth* on the planted rows - if your kappa there is low, the rubric
was ambiguous, not necessarily you wrong; (2) the **disagreement list** at the bottom - each line is a case where the best
end-to-end judge and you differ; classify each as judge error, label ambiguity, or your own slip.
